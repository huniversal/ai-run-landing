AI가 일하는 동안,
메뉴바에서 지켜보세요.

Desktoto는 AI Agent 세션의 진행 상태를 메뉴바의 작은 캐릭터로 보여줘요.작업이 끝났는지, 내 답을 기다리는지 창을 열지 않고도 알 수 있어요.

GitHub에서 보기

문제

세션을 여러 개 돌리면, 놓치게 돼요.

다른 창에서 작업하다가, 끝난 지 한참 뒤에야 알게 돼요.

승인 창이 떠 있어서 AI가 멈춰 있는데, 그걸 모르고 기다려요.

컨텍스트가 얼마나 찼는지는 열어 보기 전에는 알 수 없어요.

상태

캐릭터가 지금 상황을 알려 줘요.

달리는 중

작업이 진행 중이에요. 여러 세션 중 하나라도 돌고 있으면 계속 달려요.

폭죽

작업이 끝났어요. 캐릭터 뒤에서 작은 폭죽이 터지고 macOS 알림이 와요.

물음표

승인이나 답변이 필요해요. 사람을 기다리는 세션이 있으면 물음표가 떠요.

보라색 점

확인하지 않은 완료가 있어요. 패널을 열어서 확인하면 사라져요.

졸음

10분 동안 아무 활동이 없으면 캐릭터가 눈을 감고 졸아요. 새 작업이 시작되면 바로 깨요.

기능

필요한 것만 보이게 했어요.

한 패널에 모든 세션

제목, 컨텍스트 사용률, 막대만 보여요. 모델과 토큰 수는 마우스를 올렸을 때만 펼쳐져요. 승인이나 답변이 필요한 세션은 맨 위로 올라와요.

카드를 누르면 그 세션으로

Claude 데스크탑 앱의 대화는 앱에서 열고, 터미널 세션은 iTerm2나 Terminal의 해당 탭을 앞으로 가져와요.

알림을 눌러도 이동해요

macOS 알림으로 “작업이 끝났어요”, “승인이 필요해요”, “답변이 필요해요”를 알려요. 알림을 누르면 해당 세션으로 가요.

컨텍스트 사용률

모델마다 다른 컨텍스트 창 크기를 반영해서 사용률을 계산해요. 창 크기를 확정하지 못하면 숫자 앞에 ~를 붙여서 추정값이라고 알려요.

AI 사용량도 한눈에

Claude와 Codex의 5시간·주간 한도를 패널 맨 위에 고정해서 보여줘요.얼마나 썼는지와 초기화까지 남은 시간을 알 수 있고, 한도에 가까워지면 막대 색이 바뀌어요.Claude는 데스크탑 앱을 켜 두면 1분 안팎으로, Codex는 패널을 보는 동안 30초마다 갱신돼요. 오래된 값은 “52분 전 기준”처럼 알려요.

개인정보

내 대화는 컴퓨터 밖으로 나가지 않아요.

Desktoto는 대화 내용을 인터넷에 보내지 않아요.내 컴퓨터에 이미 있는 기록을 읽기만 하고, Codex 사용량만 Codex 프로그램에 물어봐요.

읽는 것
~/.claude/projects와 ~/.codex/sessions의 세션 기록, Claude 데스크탑 앱의 세션 정보와, 앱이 내 컴퓨터에 임시로 저장해 둔 사용량 응답(5시간·주간 사용률 두 가지 값만). 제목, 모델, 토큰 사용량, 한도 사용률, 응답이 끝났는지 같은 상태만 써요. 로그인 정보는 읽지 않아요. Codex 사용량은 설치된 Codex 프로그램에 한도(사용률)만 물어봐요. 우클릭 메뉴에서 끌 수 있어요.
하지 않는 것
대화 내용을 밖으로 보내거나 따로 저장하지 않아요. 계정 정보도 다루지 않아요.
설정 파일
Claude Code를 쓰고 있으면, 처음 켤 때 Claude Code의 설정 파일(~/.claude/settings.json)에 항목 두 개를 자동으로 추가해요. 승인 대기를 알리는 hook과 사용량을 저장하는 statusLine이에요. 이미 쓰는 statusLine은 그대로 실행돼요. 바꾸기 전에 백업을 만들고, 우클릭 메뉴의 Claude 연동에서 언제든 해제할 수 있어요.

Desktoto는 개인 프로젝트예요.

Claude는 Anthropic의, Codex는 OpenAI의 상표예요. 이 프로젝트는 두 회사와 관련이 없어요.
